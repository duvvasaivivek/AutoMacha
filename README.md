# AutoMacha

Welcome to **AutoMacha**!

## Project Structure

- `backend/`: Backend application code and APIs.
- `frontend/`: Frontend web application code.
- `docs/`: Project documentation and design guides.
- `venv/`: Python virtual environment (ignored by Git).

## Setup Instructions

### Backend Setup
1. Activate the Python virtual environment:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```
2. Install backend dependencies (when configured):
   ```powershell
   pip install -r backend/requirements.txt
   ```

### Frontend Setup
1. Navigate to the frontend directory:
   ```powershell
   cd frontend
   ```
2. Install frontend dependencies (when configured):
   ```powershell
   npm install
   ```
